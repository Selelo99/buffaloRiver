# Buffalo River Resort

A responsive HTML/CSS/JavaScript concept website for a wildlife resort where Buffalo is the brand symbol, not the only animal.

## Files
- index.html — page structure and content
- style.css — responsive visual design
- script.js — mobile menu, gallery filters, lightbox and demo enquiry form
- hero-buffalo-river.png — generated buffalo/river landscape used as the hero



## Next development steps
